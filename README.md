# Creative Strategy Skills

A growing collection of reusable AI skills for creative strategy,
brand identity, and portfolio-building workflows.

Created by Adavion McDonald.

## Available skills

### Generating Brand Brief Challenge

Creates detailed fictional brand identity briefs for self-initiated
portfolio projects and design practice.

Includes:
- Company background and project context
- Target personas and audience tensions
- Creative direction and visual constraints
- Deliverables and success criteria
- Competitive landscape and client voice

[View the skill](skills/generating-brand-brief-challenge/SKILL.md)

## Example request

“Create a foundational brand identity challenge for a niche
manufacturing company. Use a full identity scope and prioritize
physical brand applications.”

## Using these skills

Each skill lives in its own folder inside `skills/`.

Use the full skill folder with an AI tool that supports Agent Skills.
Follow that tool’s instructions for installing or loading skills.
